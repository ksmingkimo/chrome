按钮区（Coverage 练习：把按钮都点一遍）

本页的六个小任务

  1. Command Menu：Ctrl+Shift+P → 输 screenshot → Capture full size screenshot；再输 dark 切暗色主题
  2. Snippets：Sources → Snippets → 新建片段改标题，Run 后看效果
  3. Coverage：Show Coverage → 录制 → 把两个按钮都点一遍 → 找出「从没被执行」的死代码
  4. 设备模拟：Ctrl+Shift+M → 选 iPhone → 看页面变黄（媒体查询生效）
  5. Lighthouse：Generate report → 记录四栏分数
  6. Local Overrides（选做）：去任意真实网站试验
