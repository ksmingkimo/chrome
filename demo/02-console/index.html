第 2 课练习 · 报错满天飞

按钮区

打开 Console（F12 → Console 标签，或直接按 Ctrl+Shift+J），这个页面会「说话」。

任务清单

  1. 看页面载入时 Console 里已经说了什么（分清 log / warn 的样式）
  2. 点「报错」按钮，让红色错误出现，然后点错误信息跳转到出错的代码行
  3. 用 Console 顶部的过滤器，试试只看 Errors、只看 Warnings
  4. 点「打印表格」按钮，看 console.table 的效果
  5. 在输入行里依次执行：2+3、$0、$$('button').length、$_
  6. 点「加载不存在图片」按钮，看网络加载失败的错误长什么样
