第 5 课练习 · 按钮失灵

商品区

商品：无线鼠标 ¥99

浏览人数：0（这个数字会自己悄悄变化，是谁在改它？）

任务清单

  1. 先点「立即购买」和「加入购物车」，看看谁没反应
  2. 谜题 A：Sources 面板 → 右侧 Event Listener Breakpoints → 展开 Mouse → 勾 click；再分别点两个按钮，看哪个按钮会让你停进代码里 → 找出「没反应」的原因并修复
  3. 谜题 B：Elements 里右键「浏览人数」数字 → Break on → subtree modifications → 等它变化，看 Call Stack 抓出幕后黑手（进阶：换成条件断点，数字 >= 3 才停）
  4. 谜题 C：Sources 里勾 XHR/fetch Breakpoints → Any XHR or fetch → 刷新页面 → 看程序停在哪一行、Call Stack 里谁发起的请求；再点「刷新数据」按钮体验一次
  5. 用完记得取消勾选 / 移除断点
