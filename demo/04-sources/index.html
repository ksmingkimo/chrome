第 4 课练习 · 算错的账单

购物车

商品单价数量
键盘100
鼠标50

活动规则：满 300 元打九折

任务清单

  1. 先直接点「计算总价」，看 Console 里出现什么报错 → 用报错三件套定位并修掉 bug①（提示：循环条件多了半格）
  2. 修好后再点「计算」：数字出来了，但不对（键盘 100×2 + 鼠标 50×3 = 350，打九折应得 315）
  3. 打开 Sources 面板，在左侧文件树找到本页面，在 applyDiscount 函数第一行点行号打上断点
  4. 再点「计算总价」→ 程序暂停、页面冻结 → 观察右侧 Scope（变量值）与 Call Stack（调用栈）
  5. 按 F10 单步执行，盯着 total 的变化，走到它变错的那一步 → bug② 现形
  6. 修好 bug②，刷新页面验证结果 = 315
